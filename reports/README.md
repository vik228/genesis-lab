# Reports

Findings from the implementations, plus paper-style notes and result charts.

A "finding" here means a measurement that is **not in the paper**. The papers'
own claims get reproduced in the notebooks; this directory is for what turned up
past them.

- [postable-findings.md](postable-findings.md) - running list of candidates, with
  status. Start here.

Per-finding writeups get their own file, named
`<paper-slug>-<short-claim>.md`.
