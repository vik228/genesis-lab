01

Ground rules

Three things that stay fixed for every layer in every network.

01

A gradient has the shape of its variable. L is a scalar, so dX (meaning ∂L/∂X) always has exactly the shape of X.

02

Each layer has one local job. It receives dY from above and turns it into the gradient of its own weights and the gradient of its own input. It never needs to know what the loss is.

03

The nudge is the definition. Change one number by 0.1, redo the forward pass, and divide the change in L by 0.1. Every formula below is a shortcut for that.

Where dy comes from
L = y1 - y2          dy = [1, -1]     the coefficients of y in L
L = 3*y1 - y2        dy = [3, -1]
A different loss gives a different dy. The layer's job stays the same.
02

Linear layer

Rule to remember

The gradient of a wire is the value at its input times the error at its output.

The gradient of an input is the errors travelling back along the same wires.

W_kj is the wire from input k to output j. Row = which input it leaves, column = which output it enters. That is why W has shape (D_in, D_out).

Forward: outputs collect

Each output reads its column of W: y_j = Σ_k x_k W_kj

Backward: inputs collect

Each input reads its row of W: dx_k = Σ_j W_kj dy_j

Playbook card · Y = XW + b
X: (B, D_in)    W: (D_in, D_out)    b: (D_out)    Y, dY: (B, D_out)

dW = Xᵀ dY        (D_in, D_out)   input value × output error, summed over the batch
dX = dY Wᵀ        (B, D_in)       own row of wires × errors, no sum over the batch
db = dY.sum(0)    (D_out)         just dy, summed over the batch
The transposes are how the picture is written as a matrix product. Xᵀ lines up one feature across all examples so the batch sum can happen. Wᵀ reads rows where the forward pass read columns.
What appears inContainsConsequence
dWxAn input that is zero teaches its wires nothing on that example.
dXWThe gradient going back is scaled by the weights. It does not depend on x.
dbdy onlyNo input multiplies the bias, so nothing scales its error.
Shape matching is a check, not the reasonFor a square layer (D_in == D_out) both dY W and dY Wᵀ have a valid shape, so shapes cannot pick the order. The wire picture can.

Worked example

One layer, 3 inputs, 2 outputs, loss L = y1 - y2. Every number below can be recomputed by hand.

Setup and forward

y1y2
x1 = 1W_11 = 1W_12 = 0
x2 = 2W_21 = 2W_22 = 1
x3 = 3W_31 = 0W_32 = -1
y1 = 1*1 + 2*2 + 3*0    =  5
y2 = 1*0 + 2*1 + 3*(-1) = -1
L  = 5 - (-1)           =  6          dy = [1, -1]

One wire by nudging

W_21: 2 -> 2.1
y1 = 1*1 + 2*2.1 + 3*0 = 5.2      y1 +0.2, scaled by x2 = 2
L  = 5.2 - (-1)        = 6.2      L  +0.2, scaled by dy1 = 1
dW_21 = 0.2 / 0.1 = 2 = x2 * dy1

W_32: -1 -> -0.9
y2 = 0 + 2 + 3*(-0.9)  = -0.7     L = 5.7
dW_32 = -0.3 / 0.1 = -3 = x3 * dy2

Full dW: row's x times column's dy

dy1 = 1dy2 = -1
x1 = 11-1
x2 = 22-2
x3 = 33-3

This grid is the outer product xᵀ dy, shape (3,1)(1,2) -> (3,2). W_31 is 0 but dW_31 = 3: the gradient of a wire depends on its two ends, not on its own value.

One input by nudging

x2: 2 -> 2.1    (x2 feeds both outputs)
y1 = 1 + 2.1*2 + 0 =  5.2         +0.2 via W_21 = 2
y2 = 0 + 2.1*1 - 3 = -0.9         +0.1 via W_22 = 1
L  = 5.2 - (-0.9)  =  6.1
dx2 = 0.1 / 0.1 = 1 = W_21*dy1 + W_22*dy2 = 2 - 1

x3: 3 -> 3.1    (x back at [1, 2, 3.1])
y1 = 1 + 4 + 3.1*0 = 5            unchanged, W_31 = 0
y2 = 0 + 2 - 3.1   = -1.1         L = 6.1
dx3 = 1 = 0*1 + (-1)*(-1)
dx = dy Wᵀ = [1, 1, 1]            all ones is a coincidence of these numbers
dy = [1, 0]  ->  dx = [1, 2, 0]   column 1 of W: only the y1 wires carry error

Batch of 2

X = [ 1  2  3 ]      dY = [ 1  -1 ]      L = sum over both examples of (y1 - y2)
    [ 0  1  1 ]           [ 1  -1 ]

example 1 grid     example 2 grid     dW = Xᵀ dY
[ 1  -1 ]          [ 0   0 ]          [ 1  -1 ]
[ 2  -2 ]     +    [ 1  -1 ]     =    [ 3  -3 ]
[ 3  -3 ]          [ 1  -1 ]          [ 4  -4 ]

04

Fan-out rule

Rule to remember

Whatever is used in N places going forward gets the sum of N gradients coming back.

ForwardBackwardFormula
copy: x goes to many placessumdx = dA + dB + ...
sum: s = Σ x_icopydx_i = ds
mean: m = Σ x_i / Ncopy / Ndx_i = dm / N

Broadcasting is a copy. The bias is broadcast to B rows, so db = dY.sum(0). No extra averaging: if the loss is a batch mean, the 1/B is already inside dY.

Already seen three times in the worked example: dx2 summed over 2 outputs, dW summed over 2 examples, db1 summed over 2 examples.

Two paths: one direct, one through an operation

x = 2      a = 3*x = 6      y = x + a = 8      L = y

x: 2 -> 2.1
a = 6.3    y = 2.1 + 6.3 = 8.4               L +0.4

direct path     x +0.1 -> y +0.1             grad 1
path through a  x +0.1 -> a +0.3 -> y +0.3   grad 3
dx = 1 + 3 = 4

a = 0.001*x  ->  dx = 1.001                  the direct path alone still gives 1

Sum and mean

x = [1, 2, 3]

s = 6      L = 5*s      ds = 5      dx = [5, 5, 5]
m = 2      L = 5*m      dm = 5      dx = [5/3, 5/3, 5/3]
Carry forward
  • A direct add path (y = x + a) always contributes gradient 1, however weak the other path is.
  • A mean touches every element with weight 1/N. BatchNorm and LayerNorm backward are built from this.
05

Activations

Rule to remember

Gradient from above times the slope of the curve at that point.

Playbook card · A = f(Z)
Z, A: (B, D)

dZ = dA * f'(Z)       (B, D)     elementwise, no sum, no transpose
Each z_i feeds only its own a_i. No mixing, so nothing to sum and nothing to transpose.

ReLU: a gate that is 0 or 1

z  = [2, -1, 0.5]        a = [2, 0, 0.5]
L  = 1*a1 + 2*a2 + 3*a3 = 3.5         da = [1, 2, 3]

z1: 2   -> 2.1     L 3.5 -> 3.6       dz1 = 1     gate open, da passes
z2: -1  -> -0.9    L unchanged        dz2 = 0     gate shut, da2 = 2 is dropped
z3: 0.5 -> 0.6     L 3.5 -> 3.8       dz3 = 3

dz = da * (z > 0) = [1, 0, 3]

tanh: a gate that depends on z

At z = 4 the output is already at 0.999 with nowhere left to go, so the curve is flat and almost nothing passes. That is saturation. The nudge slope and the exact slope differ slightly because 0.1 is not a small nudge.

06

The two multipliers

Where vanishing and exploding gradients come from. This is the bridge to the next step.

Going back through one layer, the gradient is multiplied by two things:

MultiplierFromCan do
f'(z)Activation, section 05Only shrink (tanh, sigmoid) or gate (ReLU)
WᵀLinear layer, section 02Shrink or grow
10 sigmoids in a row, best case (every z = 0):

0.25^10 ≈ 0.00000095            about a million times smaller, before W is counted

Vanishing or exploding is decided by the product of these two, repeated once per layer.

07

Slips to watch

Mistakes actually made while working through this, and the fix for each.

01

dY/dW is X, not W. For Y = XW the derivative with respect to W brings out X. The scalar chain rule tells you which things multiply; the wire picture tells you the order and the transpose.

02

Wire gradient uses x, input gradient uses W. dW_32 = x3 * dy2 = -3 is not dx3. A wire's change is scaled by its input; an input's change is scaled by its wires.

03

Reset before every nudge. Each nudge starts from the original numbers. Carrying x2 = 2.1 into the x3 nudge gave y1 = 5.2 where it should have stayed 5.

04

Check the sign against the nudge. If L went up when the variable went up, the gradient is positive. Redo the forward pass line by line when the two disagree.

05

A variable can appear more than once. In y = x + a with a = 3x, both the direct x and the a change when x is nudged.
