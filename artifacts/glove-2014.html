The information GloVe keeps

A local prediction objective learns from word-context events, but does not retain their exact corpus-wide counts. GloVe builds those counts explicitly, then asks the vectors to reproduce their useful structure.

Co-occurrence statistics
Xik = count of context word k around target word i
Xi = Σk Xik
P(k | i) = Xik / Xi. The row total is context mass, not necessarily token frequency.
02

From a probability ratio to a dot product

Hold context k fixed and compare how strongly it associates with two targets i and j. Their ratio isolates the context's contrast.

01

Compare conditional probabilities. A context that occurs with both targets equally has ratio 1; a distinguishing context pushes the ratio above or below 1.

02

Take logs. The ratio becomes a difference that vector scores can represent.

03

Represent each score. Let a target-context score be wi · ck. Subtracting target scores gives a relation vector projected onto the fixed context.

04

Substitute the count ratio. Expanding P(k|i)=Xik/Xi introduces the target row total; a target bias absorbs that target-only offset. Symmetry gives a context bias.

The derivation spine
Contrast
F((wi − wj) · ck) = Pik / Pjk
Log ratio
(wi − wj) · ck = log Pik − log Pjk
Count form
log Pik = log Xik − log Xi
Prediction
wi · ck + bi + dk ≈ log Xik
The biases are learned parameters in the final objective; they are not fixed equal to observed row sums.
03

Weighted least squares

Each observed pair supplies a positive count and a log-count target. The weight limits the influence of both unreliable rare pairs and extremely frequent pairs.

Per-pair weight and objective
f(Xik) = min((Xik / xmax)α, 1)
J = Σi,k : Xik > 0 f(Xik) [wi · ck + bi + dk − log Xik]2
Paper values: xmax = 100, α = 3/4. The target remains the raw log count, including for pairs above xmax.

What clipping does

Counts below 100 receive a fractional weight. Counts at or above 100 receive weight 1; their target still grows as log(count).

Why it is a squared error

The model predicts one scalar for each observed pair. Squaring the residual penalizes large deviations; the weighting function controls each pair's influence.

05

Building the global table

With radius C=1, each adjacent pair contributes in both target-context orders. Chunking limits the temporary pair tensor; a final merge combines repeated pairs.

Example sentence
ice is cold
(ice, is), (is, ice)
Adjacent positions contribute both ordered pairs.
(is, cold), (cold, is)
At a corpus boundary, missing context is padding and contributes no pair.
chunk-local unique → global combine
The final text8 matrix stores only observed pairs as triplets (target ID, context ID, count), not a dense V×V array.

For the full text8 stream, C=1 produced 34,010,412 ordered context events and 7,582,569 unique ordered pairs. Counts are symmetric under this window, but (i,k) and (k,i) remain separate training rows.

Implementation vs paperThis run used C=1, raw unit counts, and SGD. The paper's experiments use a wider context window with inverse-distance contributions and AdaGrad. So this is a working GloVe objective, but not an exact reproduction of the paper's complete training setup.
